# Peligood Bid Radar

페리굿이 지원/참여 가능성을 검토할 수 있는 공공·기관 입찰/사전규격/반복발주 후보를 모으는 정적 레이더입니다.

## Development memory
코드나 일일 조사 데이터를 바꾸기 전에 아래 문서를 먼저 읽습니다.

- `AGENTS.md`
- `docs/project-memory.md`
- `docs/regression-guardrails.md`
- `docs/decision-log.md`

검색은 VR/AR/메타버스라는 제목 키워드에 한정하지 않고 과업/RFP의 실제 내용까지 봅니다. 현재 입찰·사전규격 항목은 공식 원문 또는 실제 조사에 사용한 상세 URL을 남겨야 합니다.
